# ~/ai/tools — скрипты, которыми собраны таблица моделей, workflow и проверки

Всё здесь только читает ComfyUI и модели и пересобирает документы. Генерацию запускает только `test/` (скилл `/comfy-test`).

| Папка | Что внутри |
|---|---|
| `table/` | Таблица моделей: `models_data.py` — данные (тексты, время, промпты, плюсы и минусы, лицензии); `estimate.py` — калькулятор времени и памяти; `build_table.py` собирает `~/ai/models.md` и `~/ai/models.xlsx` (листы Фото, Видео, Аудио, Апскейл, Утилиты и LLM) |
| `export/` | Список workflow (`build_list.py`), экспорт UI и API-копий в `~/ai/workflows` через фронтенд ComfyUI (`export_api.sh`, `export.mjs`, `cdp.mjs`), проверка API-копий (`validate_api.py`), README (`make_readme.py`). `fixed/` — исправленные примеры из репозиториев нод и workflow NetaYume с Tensor.Art |
| `check/` | `verify.py` — все модели для шаблонов и своих workflow на месте, загрузки целые; `check_nodes.py` — все ноды и файлы, на которые ссылаются workflow, существуют; `check_widgets.py` — число виджетов у нод; `manifests/` — что и откуда скачивалось |
| `test/` | Тест модели из таблицы (скилл `/comfy-test`): `run.py` — прогон партии задач через API (только workflow из строки модели; `--prep` — входные файлы, `--resume` — дождаться после обрыва), результаты в `~/Videos/ai/tests/<id>/<стиль>/`; `gallery.py` — `index.html` из лога и заметок; `look.sh` — сетки, кропы, листы кадров, спектрограммы; `transcribe.sh` — whisper рядом с ComfyUI |
| `patches/heartmula/` | Оригинал и diff патча памяти HeartMuLa. После обновления ноды патч слетит: накати `patch.diff` заново |
| `research/` | `web.md` — заметки из интернета (промпты, бенчмарки, калибровка); `notes/` — заметки из самих шаблонов |

## Добавил или поменял модель

1. Допиши или поправь запись `m(id=…, …)` в `table/models_data.py`. Образец — соседние записи; поле `wf` — список `категория/имя workflow`.
   - Строка таблицы — модель × режим. Режимы различаются входом (текст, картинка, видео, аудио, маска): `split=[dict(id=…, mode='вход → выход', wf=[…], cap={…}), …]`, каждый режим может переопределить любое поле модели, `add=dict(поле='…')` дописывает к нему текст. Первый режим держит id модели, остальные — с суффиксом (`-i2v`, `-edit`, `-control`…). Один режим — `mode` и `cap` прямо в `m()`.
   - `cap` — умения для колонок листа (ключи — в `SHEETS` в начале файла): `'✓ …'`, `'—'` или `'?'` (не проверено). Лист выбирается по `cat`.
   - После реального запуска обнови выводы в поле `exp=dict(<стиль>='…')` того режима, которым работал (суть: что учитывать, а не что генерировал), ключи — из `STYLES` (`real`, `anime`, `drawn`, `graphic`, `sound`). Он попадёт в колонки «Опыт».
2. Пересобери таблицу:
   ```bash
   cd ~/ai/tools/table && python3 -I build_table.py
   ```
3. Добавь строку в каталог скилла `~/.claude/skills/comfy/SKILL.md`.

## Добавил свой workflow

1. Сохрани его в ComfyUI: он окажется в `~/ai/comfyui/user/default/workflows/`.
2. Впиши его в словарь `OWN` в `export/build_list.py` (имя файла → категория). Шаблон ComfyUI вписывается в `CAT`.
3. Сделай UI- и API-копии и пересобери README. Занимает пару минут, порты 8199 и 9333 должны быть свободны:
   ```bash
   ~/ai/tools/export/export_api.sh "часть имени"   # без аргумента — все workflow
   ```
4. Если workflow относится к модели из таблицы, добавь его в поле `wf` этой модели (см. выше).
